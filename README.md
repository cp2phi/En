# English Practice

本机运行的英语练习工具。目标：单词、说、写一起提升，为 Improv 101 和 Toastmasters 做准备。

## 运行

需要 Python 3.10 以上，没有第三方依赖。

```bash
python3 run.py          # 打开 http://127.0.0.1:8765
python3 -m unittest discover -s tests -t .   # 运行测试
```

第一次使用先到「设置」里填 OpenAI key：AI 解释、写作/口语反馈、录音转文字都要用到。没有 key 也能练，只是没有反馈，口语只记录时长。

## 功能

| 页面 | 作用 |
|---|---|
| 填空 | 中文 → 英文填空，一直出题。按词类（或语法专题）、场景、难度筛选。词、词形、拼写都对才算对。 |
| 错题集 | 所有做错过的题，中英对照通读，或全部重做一遍。 |
| 一直写 | L1~L6 六级阶梯（单句翻译 → 聊天消息 → 邮件 → 故事观点 → 长文 → 演讲稿）。每级合格 5 次解锁下一级。可以先写中文占位。提交后给出地道改写、最多 3 条重点问题、可一键入库的表达。 |
| 一直说 | L1~L6 六级阶梯（跟读 → 30 秒 → 讲经历 → 观点 → 即兴故事/反驳 → 即兴演讲）。录音、计时、卡壳键，说完自动转文字并给反馈。 |
| Improv | 按 Improv 101 的课程分组：Yes and、脱口而出、编故事、高低姿态、给理由、交代场景、听懂游戏规则、救场用语。 |
| Toastmasters | Table Topics（绿/黄/红灯计时）、Ice Breaker 自我介绍、点评、会议角色用语。 |
| 统计 | 等级和经验、连续天数、写的词数/速度/错误率、开口时长/语速/卡壳/口头禅、今天 vs 近 7 天 vs 前 7 天、最近 14 天。 |
| 背单词 | 忘记 / 模糊 / 记住 / 永不再出现。先复习到期的，再学新词。 |
| 添加 / 积累 | 粘贴句子，指出不懂的部分，AI 解释并填好卡片，勾选要保留的解释。 |
| 单词本 | 查看、搜索、删除。 |
| 设置 | OpenAI key、模型、英式或美式朗读、每天新词上限。 |
| 同步 | 把 `data/` 提交并推送到 git 远程，换电脑后 `git pull` 就能接着练。 |

练习模块各有自己的题库，不围绕生词出题；练习中遇到不会的表达，点「加入生词」沉淀到单词本。

## 复习规则

- **忘记**：当天至少再出现 2 次，然后第二天。
- **模糊**：当天至少再出现 1 次，间隔不拉长。
- **记住**：间隔依次为 1、3、7、15、30、60、120 天。
- **填空**：第一次就做对的题不再出现（可以点「其实是蒙对的」加入重做）；做错或看了答案的题按「忘记」处理，连续做对到间隔 15 天后算通过。
- 填空题和单词都可以选「永不出现」。

## 目录

```
app/         后端（标准库 HTTP 服务、间隔重复、判题、练习与统计、git 同步、OpenAI 调用）
static/      前端（原生 HTML/JS）
questions/   填空题库：questions/<词类>/<场景>.json
prompts/     写、说、Improv、Toastmasters 题库：prompts/<模块>/<分组>.json
data/        你的练习记录（同步按钮上传的就是这个目录），data/journal/ 保存每次写和说的原文与反馈
docs/        出题规范
tools/       题库检查脚本
tests/       测试
```

`config.local.json` 保存 OpenAI key，已在 `.gitignore` 里，不会被同步上传。

## 加题 / 扩题

规范见 [docs/content-guide.md](docs/content-guide.md)。填空题在 `questions/<词类>/<场景>.json` 里加一行，`{}` 里是答案，`|` 分隔其他可接受的答案，`::` 后面是给学习者看的提示，一句话可以有多个空：

```json
{"id":"v-work-01","level":2,"g":"3sg","zh":"她每周一主持团队例会。","en":"She {runs|chairs|leads} the team meeting every Monday."}
{"id":"g-past-001","level":2,"g":"past","zh":"我昨天去了超市。","en":"I {went::go} to the supermarket yesterday."}
```

加完运行 `python3 tools/check_bank.py questions/<词类>`，打印 OK 才算合格。`id` 一旦用过就不要改，练习记录靠它对应。

## 费用

- 写作和口语反馈用 `gpt-4o-mini`（可在设置里改），每次不到 1 美分。
- 录音转文字用 `whisper-1`，约 0.006 美元/分钟，练两小时口语约 0.7 美元。

## 后续

- 题量扩到 5 倍（动词 1000 题、名词数千题）：按出题规范继续加文件即可。
- 口语对话模式（AI 扮同事来回聊）。
