# English Practice

本机运行的英语练习工具。目标：单词、说、写一起提升，为 Improv 101 和 Toastmasters 做准备。

## 运行

需要 Python 3.10 以上，没有第三方依赖。

```bash
python3 run.py          # 打开 http://127.0.0.1:8765
python3 -m unittest discover -s tests -t .   # 运行测试
```

## 现在有的功能

| 页面 | 作用 |
|---|---|
| 填空 | 中文 → 英文填空。按词类、场景、难度筛选，一直出题。词、词形（时态/人称/单复数）、拼写都对才算对。 |
| 错题集 | 所有做错过的题，中英对照通读，或全部重做一遍。 |
| 背单词 | 忘记 / 模糊 / 记住 / 永不再出现。先复习到期的，再学新词。 |
| 添加 / 积累 | 粘贴句子，指出不懂的部分，AI 解释并填好卡片，勾选要保留的解释。 |
| 单词本 | 查看、搜索、删除。 |
| 设置 | OpenAI key、模型、英式或美式朗读、每天新词上限。 |
| 同步 | 把 `data/` 提交并推送到 git 远程，换电脑后 `git pull` 就能接着练。 |

## 复习规则

- **忘记**：当天至少再出现 2 次，然后第二天。
- **模糊**：当天至少再出现 1 次，间隔不拉长。
- **记住**：间隔依次为 1、3、7、15、30、60、120 天。
- **填空**：第一次就做对的题不再出现（可以点「其实是蒙对的」加入重做）；做错或看了答案的题按「忘记」处理，连续做对到间隔 15 天后算通过。
- 填空题和单词都可以选「永不出现」。

## 目录

```
app/         后端（标准库 HTTP 服务、间隔重复、判题、git 同步、OpenAI 调用）
static/      前端（原生 HTML/JS）
questions/   题库：questions/<词类>/<场景>.json
data/        你的练习记录（同步按钮上传的就是这个目录）
tests/       测试
```

`config.local.json` 保存 OpenAI key，已在 `.gitignore` 里，不会被同步上传。

## 加题

在 `questions/<词类>/<场景>.json` 里加一行即可，`{}` 里是答案，`|` 分隔其他可接受的答案，一句话可以有多个空：

```json
{"id":"v-work-01","level":2,"g":"3sg","zh":"她每周一主持团队例会。","en":"She {runs|chairs|leads} the team meeting every Monday."}
```

`id` 一旦用过就不要改，练习记录靠它对应。
